# Development Guide — whattoeat

## Stack
- **React 19** + **Vite** — UI framework and build tool
- **Three.js** + **@react-three/fiber** — 3D dice animation
- **Capacitor 8** — wraps the web app into iOS / Android native apps

---

| Tool | Mac | Windows |

## Daily Development (both Mac & Windows)

```bash
git pull          # always start with latest code
npm install       # only if package.json changed
npm run dev       # starts dev server at http://localhost:5173
```

Test in **Chrome DevTools → Toggle device toolbar** (`Cmd/Ctrl + Shift + M`)  
Use preset: **iPhone 14 Pro** (393 × 852) for primary testing.

---

## Deploying to a Device / Simulator

### Every time you change code and want to test natively:

```bash
npm run build     # build the web app into /dist
npx cap sync      # copy /dist into ios/ and android/ native projects
```

### iOS (Mac only)
```bash
npx cap open ios  # opens Xcode
```
In Xcode: select a simulator or your plugged-in iPhone → press **▶ Run**

### Android (Mac or Windows)
```bash
npx cap open android  # opens Android Studio
```
In Android Studio: select a device → press **▶ Run**

## Git Workflow

```bash
git checkout -b feature/your-feature-name   # new branch for each feature
# ... make changes ...
git add .
git commit -m "feat: describe what you did"
git push origin feature/your-feature-name
# open a Pull Request on GitHub
```

### What to commit
| Path | Commit? |
|------|---------|
| `src/` | ✅ yes |
| `capacitor.config.json` | ✅ yes |
| `ios/` | ✅ yes (native configs) |
| `android/` | ✅ yes (native configs) |
| `dist/` | ❌ no (add to .gitignore) |
| `node_modules/` | ❌ no (already ignored) |

## Project Structure

```
src/
  components/
    DiceRoller.jsx        # orchestrates the roll animation + phases
    DiceRoller.css        # styles, curtains, overlays
    ThreeDiceStage.jsx    # Three.js scene (dice only)

```

## Common Commands

| Command | What it does |
|---------|-------------|
| `npm run dev` | Start dev server |
| `npm run build` | Build for production |
| `npx cap sync` | Sync web build to native projects |
| `npx cap open ios` | Open Xcode |
| `npx cap open android` | Open Android Studio |

| `npx cap run android` | Build + run on Android emulator |

## Useful Tips

- **Safe areas**: Use `env(safe-area-inset-*)` CSS for iPhone notch / home bar padding
- **Viewport**: Always use `dvh` instead of `vh` on mobile (handles browser chrome correctly)
- **Touch**: Add `touch-action: manipulation` on tappable elements to remove 300ms tap delay
- **Hot reload in browser**: Changes in `src/` reflect instantly via Vite HMR — no rebuild needed
- **Hot reload on device**: Not instant — requires `npm run build && npx cap sync` then re-run in Xcode/Android Studio
